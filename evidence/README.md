# Project Evidence

This directory is used to organise supporting evidence generated during
the VaultFive project.

Evidence may include:

- Milestone snapshots
- Sprint evidence
- Screenshots
- Testing evidence
- UI development evidence
- Project-management evidence
- Relevant GitHub evidence
- Supporting artefacts for the final report

## Evidence Principles

Evidence should reflect work that was actually completed by Team 4.

Files should use clear names and, where appropriate, include the date
or milestone to which they relate.

Sensitive information, passwords, personal data and unnecessary private
communications must not be stored in this directory.
