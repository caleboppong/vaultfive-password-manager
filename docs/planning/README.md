# Project Planning

This directory contains planning and project management artefacts for
the VaultFive project.

Documents may include:

- Project Initiation Document (PID)
- Project schedule
- Gantt chart
- Sprint plans
- Sprint reviews
- Milestones
- Project status reports
- Action logs
- Decision and change records

Planning documents will be reviewed throughout the project to compare
planned progress against actual progress.
