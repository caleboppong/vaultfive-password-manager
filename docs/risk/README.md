# Risk Management

This directory contains the VaultFive project risk-management
documentation.

The risk register will record:

- Risk ID
- Risk description
- Likelihood
- Impact
- Risk rating
- Mitigation
- Owner
- Current status

Risks will be reviewed throughout development and updated when new
technical, project or team risks are identified.

## Primary Responsibility

Eray — Quality Assurance & Risk

Risk management remains a shared responsibility across Team 4.
