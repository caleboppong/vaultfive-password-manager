# Meeting Records

This directory contains records of formal Team 4 project meetings.

## Meeting Schedule

Formal team meetings are normally held every Wednesday from
15:30 to 17:00 using Microsoft Teams.

## Communication

Microsoft Teams is used for formal project meetings and project
communication.

The Team 4 WhatsApp group is used for quick questions, reminders and
informal out-of-hours coordination.

Important project decisions arising from informal communication should
be recorded in the appropriate formal project artefact.

## Meeting Records

Meeting records may contain:

- Date and time
- Attendance
- Agenda
- Progress updates
- Blockers
- Requirements or scope changes
- Risk updates
- Testing updates
- Decisions
- Actions
- Action owners
- Due dates
