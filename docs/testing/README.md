# Testing and Quality Assurance

This directory contains testing and quality-assurance documentation for
VaultFive.

Testing may include:

- Functional testing
- Negative testing
- Boundary testing
- Integration testing
- Security-oriented testing
- Usability and accessibility testing
- Regression testing

## Test Evidence

Where appropriate, test records will contain:

- Test ID
- Requirement ID
- Test description
- Preconditions
- Test data
- Test steps
- Expected result
- Actual result
- Pass/Fail status
- Related defect or evidence

Failed tests will be recorded rather than removed. Identified defects
will be corrected where possible and relevant tests will then be
repeated.

## Primary Responsibility

Eray — Quality Assurance & Risk

All Team 4 members are expected to participate in testing.
